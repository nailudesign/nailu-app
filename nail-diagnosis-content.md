## 🎨 診断結果 (4タイプ)

---

### 【A】シアー＆ソフトネイル
#### ふんわり優しい、癒し系ネイル

**あなたにぴったりな理由:**  
透明感のあるシアーカラーとソフトなニュアンスデザインが、あなたの優しい雰囲気にマッチ。ナチュラルだけど手抜きじゃない、ちょうどいい可愛さ。

**こんなときにおすすめ:**
- カフェデートや友達とのまったり時間
- オフィスでも浮かない上品ネイル
- 「頑張りすぎてないのにおしゃれ」を叶えたいとき
- 自分を労わりたい、癒されたい気分のとき

**キーワード:**  
ミルキーベージュ / ニュアンス / シアーピンク / パール / 押し花 / ガラスフレンチ

---

### 【B】ヤミかわネイル
#### 繊細でエモい、自分だけの世界観

**あなたにぴったりな理由:**  
ダークトーンとキラキラの組み合わせが、あなたの繊細で複雑な感情を表現。「病みかわいい」「エモい」が好きなあなたの感性にぴったり。

**こんなときにおすすめ:**
- ライブや推し活で気分を上げたいとき
- 地雷系・量産型コーデに合わせたい
- 「普通じゃつまらない」と感じるとき
- 自分の世界観を大切にしたいとき

**キーワード:**  
ブラック / ボルドー / ハート / リボン / ホログラム / Y2K / 地雷系 / ベルベット

---

### 【C】クール＆ミニマルネイル
#### すっきり洗練、かっこいい私

**あなたにぴったりな理由:**  
無駄のないシンプルデザインとモダンなカラーが、あなたのクールな美意識にマッチ。「引き算の美学」を知っている大人っぽいあなたへ。

**こんなときにおすすめ:**
- 仕事やプレゼンで自信を持ちたいとき
- シンプルコーデを格上げしたい
- 「かっこいい」と言われたいとき
- 自分をシャープに見せたい気分のとき

**キーワード:**  
グレージュ / ヌード / ミラーネイル / ワンカラー / マグネット / ストーンアート

---

### 【D】ガーリー＆スウィートネイル
#### 甘くてときめく、愛されネイル

**あなたにぴったりな理由:**  
ピンクやリボン、パールの可愛さ全開デザインが、あなたの「好き」を詰め込んだネイル。見るたびにテンションが上がる、ときめきネイル。

**こんなときにおすすめ:**
- デートや特別な日に可愛くなりたい
- 推しカラーや好きな色を楽しみたい
- 「可愛い」って言われたいとき
- 毎日をもっとハッピーにしたいとき

**キーワード:**  
ピンク / ラベンダー / リボン / パール / チークネイル / シロップネイル / ぷっくりジェル

## 🎯 実装メモ

### 診断ロジック
- A が多い → シアー＆ソフトネイル
- B が多い → ヤミかわネイル
- C が多い → クール＆ミニマルネイル
- D が多い → ガーリー＆スウィートネイル

### 画像ファイル名規則
- Hero: `diagnosis-[type]-hero.png`
- Supporting: `diagnosis-[type]-[1-3].png`

例:
- `diagnosis-sheer-hero.png`
- `diagnosis-sheer-1.png`
- `diagnosis-sheer-2.png`
- `diagnosis-sheer-3.png`

### 合計画像数
4タイプ × 4画像 = **16枚の診断用画像**
